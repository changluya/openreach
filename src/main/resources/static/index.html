让 AI Agent 更简单地触达开放 Web

OpenReach 是面向 AI Agent 的开源 Web 访问基础设施。用统一接口完成网页搜索、文搜图和正文读取，并通过多 Provider 自动降级减少对单一搜索厂商的绑定。

5 分钟快速启动 → 查看官方接口
search(query)搜索网页，发现官网、新闻、博客、技术文档和公开信息源。
image-search(query)通过文本发现图片、缩略图、来源页面和 License 元数据。
read(url)读取公开网页，提取标题、正文、元数据和页面链接。
Core capabilities

只给 Agent 三个稳定原语

上层 Agent 依赖能力，不依赖厂商。底层 Provider 可以替换、降级和持续扩展。

S

Web Search

多搜索 Provider 自动 fallback，输出标题、URL、摘要、排名与来源，适合先发现可靠信息源。

POST /api/web/search
I

Image Search

支持 CN / GLOBAL 双路由文搜图，返回原图、缩略图、来源页、尺寸以及开放许可信息。

POST /api/web/image-search
R

Web Read

安全获取公开 HTML 页面，提取正文和元数据，并内置 URL 安全校验、跳转限制与响应体限制。

POST /api/web/read
Use cases

从“搜到”到“读懂”

OpenReach 将信息源发现与正文读取串成一条 Agent 可直接调用的 Web 访问链路。

企业 / 产品官网发现官网、产品页、解决方案、价格页、更新日志，再继续读取正文。
技术文档 / 开源项目搜索官方文档、GitHub 相关页面、技术博客和使用说明。
新闻 / 行业资讯发现新闻、媒体报道和行业动态，并读取原始来源供 Agent 交叉分析。
微信公众号公开文章尝试搜索已被搜索引擎收录的公开推文，或直接读取公开文章 URL。
Research AgentSearch 批量发现来源，再 Read 多页面，完成汇总、对比、归纳和引用。
企业智能助手给内部 Agent 增加实时 Web 信息获取能力，降低上层工具与具体厂商耦合。
内容生产搜索博客、专栏和公开内容站点，辅助摘要、选题、资料整理与事实核查。
文搜图 / 配图通过 image-search 发现图片及来源页，为内容生产和素材发现提供入口。
Quick start

一组命令启动，浏览器直接看到官网

无需 Clone 工程、无需准备 Compose 文件，准备日志目录后执行 docker run 即可启动。源码开发场景再使用 Maven。服务启动后访问 http://localhost:8080 即可看到当前官网。

打开快速启动文档
sudo mkdir -p /data/openreach/logs
sudo chown -R 10001:10001 /data/openreach/logs

docker run -d \
  --name openreach \
  --restart unless-stopped \
  -p 8080:8080 \
  -e OPENREACH_LOG_PATH=/app/logs \
  -v /data/openreach/logs:/app/logs \
  --log-driver json-file \
  --log-opt max-size=20m \
  --log-opt max-file=3 \
  codercl/openreach:latest

# Website  http://localhost:8080/
# Docs     http://localhost:8080/docs/
Agent Skill

先 check，再按需初始化

OpenReach Skill 使用 Python 标准库封装 check / search / image-search / read。Agent 的初始化状态检查只看 config.json，存在时仅做 1 次无副作用 API 探测；不存在时必须向用户索要 <OPENREACH_BASE_URL>。禁止重复探测、猜测地址、自动修复或自行 init。

下载 openreach-skill.zip 查看 Skill 用法 
python3 scripts/openreach.py check

# 仅在用户明确要求初始化时
python3 scripts/openreach.py init '<OPENREACH_BASE_URL>'

python3 scripts/openreach.py search "AI Agent" \
  --region auto \
  --provider auto \
  --limit 5

Agent flow

典型调用链路

先发现来源，再读取正文，最后把干净内容交给模型处理。

01User Question产品、公司、技术或热点问题
→
02search()发现官网、新闻、博客、公开文章
→
03read()提取标题、正文、元数据与 Links
→
04Agent总结、对比、问答、引用与继续检索
