官方接口文档

OpenReach 当前提供三个核心 HTTP POST 能力，并额外提供一个无外部依赖的 Health 接口用于部署与 Skill 初始化检查。以下参数以当前 Java DTO 和 Controller 为准。

Base URL：http://localhost:8080。所有接口路径统一位于 /api/web。

GET/api/web/health

服务连通性检查。该接口不调用外部搜索 Provider，官网 Skill 的 init 与 doctor 会把它作为使用 Search / Image Search / Read 前的环境前置条件。

curl 'http://localhost:8080/api/web/health'

成功响应：{"status":"UP","service":"openreach"}

POST/api/web/search

搜索网页并返回候选信息源。provider=auto 时按配置顺序自动降级。

请求参数

字段类型必填说明
querystring是非空搜索关键词
limitinteger否1–20，默认 10，并受服务端 max-results 限制
regionstring否默认 auto；未传等价于 auto；不同 Provider best-effort 映射
providerstring否默认 auto；可选 bing / baidu / sogou / so360 / duckduckgo

示例

curl -X POST 'http://localhost:8080/api/web/search' \
  -H 'Content-Type: application/json' \
  -d '{"query":"OpenReach AI Agent","limit":5,"region":"auto","provider":"auto"}'

响应字段：provider、query、region、count、latencyMs、items[]。每个 item 包含 rank、title、url、snippet、source。

POST/api/web/image-search

根据文本搜索图片与来源页面。

请求参数

字段类型必填说明
querystring是非空图片搜索关键词
limitinteger否1–30，默认 10，并受服务端 max-results 限制
regionstring否默认 auto；未传等价于 auto
providerstring否默认 auto；可选 bing / baidu / sogou / openverse

示例

curl -X POST 'http://localhost:8080/api/web/image-search' \
  -H 'Content-Type: application/json' \
  -d '{"query":"杭州西湖夜景","limit":8,"region":"auto","provider":"auto"}'

响应 items 可包含：rank、title、imageUrl、thumbnailUrl、sourcePageUrl、provider、source、domain、width、height、imageFormat、license、licenseUrl。

POST/api/web/read

获取公开网页并提取标题、正文、元数据和页面链接。读取链路包含 SSRF 防护和跳转限制。

请求参数

字段类型必填说明
urlstring是需要读取的非空 HTTP(S) URL
maxCharsinteger否1000–200000；服务端默认最大正文字符数为 50000

示例

curl -X POST 'http://localhost:8080/api/web/read' \
  -H 'Content-Type: application/json' \
  -d '{"url":"https://spring.io/projects/spring-boot/","maxChars":20000}'

响应字段：url、finalUrl、title、content、contentType、reader、truncated、latencyMs、metadata、links。

错误响应

错误统一返回时间戳、HTTP 状态码、错误码和信息。

{
  "timestamp": "2026-08-15T03:00:00Z",
  "status": 400,
  "code": "VALIDATION_ERROR",
  "message": "query: must not be blank"
}

常见错误码：BAD_REQUEST、VALIDATION_ERROR、UPSTREAM_ERROR、INTERNAL_ERROR。

Provider 默认顺序

  • Web Search：Bing 中国 → 百度 → 搜狗 → 360 → DuckDuckGo
  • Image Search：Bing Images → 百度图片 → 搜狗图片 → Openverse
免费搜索结果依赖公开页面结构、访问策略和网络环境，因此属于 best-effort。Openverse 使用其公开 API。
