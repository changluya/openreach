# OpenReach 项目 Logo 设计描述

> 面向开源发布的 Logo 设计说明文档。目标：让设计师、社区贡献者或 AI 绘图工具能依据本文档产出一套**统一、可识别、可扩展**的视觉识别系统。

---

## 1. 品牌定位与设计基调

**OpenReach** 是面向 AI Agent 的开源 Web 访问基础设施，核心能力为三原语：

```text
search(query)        -> 网页搜索 / 发现信息源
image-search(query)  -> 文搜图 / 发现图片
read(url)            -> 读取网页 / 提取正文
```

品牌关键词：

| 维度 | 关键词 |
|---|---|
| 功能 | 连接、触达、桥接、感知、检索、提取 |
| 气质 | 开放、可靠、敏捷、前沿、Agent 友好 |
| 技术 | 开源、基础设施、API、多 Provider 路由 |

**Logo 设计目标**：第一眼传达「一个实体（Agent）与广袤 Web 世界之间的连接/触达」，而非「搜索引擎图标」。要区别于 Google / Bing 的放大镜，避免纯「望远镜 + 地球」的俗套组合。

---

## 2. 主方案：Signal Node「触达之环」（推荐）

### 2.1 符号构成

以居中的**实心节点（Node）**代表 Agent 智能体，向外放射**三条同心圆弧（Signal Arcs）**代表三种能力原语（Search / ImageSearch / Read）持续向外“触达”网络。

```text
         ╭── 弧 3（Read，最长）
      ╭──┤
   ╭──┤  ● 节点（Agent）
   ╰──┘  ╰── 弧 2（ImageSearch）
      ╰────────── 弧 1（Search，最贴近节点）
```

- **中心节点**：圆润的实心圆点，位于图形重心，象征智能体本体与稳定的“根”。
- **三条弧线**：以节点为圆心向外扩散的同心圆弧（角度开合约 70°~100°，开口朝向一致，例如开口向右上方，呼应“向外出发”的方向感）。
- 三条弧分别对应三条能力原语，且可延展为品牌叙事（三原语矩阵）。
- 整体图形近似字母 **O**（OpenReach 首字母）的抽象变体——弧线天然围合出负空间“O 形”。

### 2.2 设计理由

1. **语义准确**：节点→弧线准确表达「Agent 通过能力接口向外触达 Web」这一项目本质，与 README 中 `search → image-search → read` 三条原语的抽象一致。
2. **去搜索化**：回避放大镜、地球仪等泛搜索符号，在 AI Agent 基础设施品类中更具差异化。
3. **简洁可缩放**：几何化构成，16px favicon 到 512px 应用图标均保持可读。
4. **可扩展**：三条弧可独立取色/命名，为多产品（Read 服务、Search 服务）提供延展空间。

### 2.3 字形与组合

- 主图形旁配 **OpenReach** 字标；`Open` 常规字重、`Reach` 可选加粗或同字重，字母间距适中偏宽，体现“基础设施”的秩序感。
- 首选字体族：无衬线几何类（如 Space Grotesk、Inter、Noto Sans SC）。
- 竖排组合（图标在上/字标在下）用于 App 图标与文档页眉；横排组合（图标在左/字标在右）用于 README 与网站导航。

## 3. 色彩规范

### 3.1 主色（推荐：科技青绿渐变）

| 角色 | 色值建议 | 说明 |
|---|---|---|
| 主色 | `#0EA5E9`（Sky 500）→ `#10B981`（Emerald 500）渐变 | 蓝→青绿，象征“开放互联网 + 可靠基础设施 + 成长性开源” |
| 节点色 | `#0F172A`（Slate 900）或深蓝 `#1E3A8A` | 中心节点用深色，制造“实心根节点”的稳定感 |
| 辅助强调 | `#F59E0B`（Amber 500）| 可选：用于某一条弧（如 Read），形成三色点缀 |

> 渐变仅用于正式 / 彩色场景；单色场景统一使用 Slate-900，保证文档印刷与 favicon 的一致性。

### 3.2 配色理由

- 与项目 Spring Boot 生态的绿色系（`#6DB33F`）保持同色相家族但更现代，弱化“框架绑定感”。
- 蓝青渐变在国际开发者生态中被普遍识别为「开放 / 云 / AI」语言（与 OpenAI 蓝绿、Web 基础设施类工具调性接近但不过度雷同）。
- 深色模式下（暗色 favicon / GitHub 深色皮肤）深蓝节点 + 亮色弧线具有良好对比度。

## 4. 备选方案

| 方案 | 符号 | 优点 | 缺点 | 定位 |
|---|---|---|---|---|
| B. Gateway Arch「网关拱门」 | 以两条对称弧线构成拱形/门洞，中心负空间为视线出口 | 传达“通道/网关”，现代 | 与部分云厂商图标近似，识别度一般 | 中 |
| C. Orbit「轨道」 | 中心节点 + 一条环绕椭圆轨道 + 一个轨道上的小星点 | 宇宙 / 搜索轨迹意象，动态感强 | 容易被理解成“行星/雷达”，偏离 Agent 基建 | 中 |
| D. Beam「三光束」 | 节点向外发出三根等宽光束（可带端点圆点） | 极简、信号/雷达语感，扩展为三能力叙事强 | 与信号类 App 图标易混淆 | 中 |
| E. O-Aperture「O 型光圈」 | 直接以粗描边 “O” 开合缺口，缺口处放一个节点 | 强绑定 OpenReach 首字母，形式极简 | 语义偏抽象，需配字标辅助解释 | 高（可作为主方案的简化变体） |

> 建议：以 **方案 A（Signal Node）** 为主符号，同时保留 **方案 E（O-Aperture）** 作为 favicon / 应用图标（小尺寸）的简化变体。

## 5. 使用与交付规格

| 项 | 规格 |
|---|---|
| 主文件 | SVG（矢量）+ PNG（512×512、1024×1024）+ favicon.ico |
| 最小尺寸 | 符号 16px 清晰可辨；字标组合 ≥ 24px |
| 安全边距 | 四周预留 ≥ 符号直径 20% 的留白 |
| 单色版本 | Slate-900 单色、反白版各一份 |
| 深色模式 | 提供亮底/暗底两套渐变与单色版本 |
| 动画可选 | 弧线逐条点亮（Search→ImageSearch→Read）作为站点加载 / 启动动效 |

## 6. 一句话设计陈述

> **“一个智能体节点，向广袤 Web 发出三条能力弧——Search、ImageSearch、Read——开放触达，万物可读。”**

---

## 7. 注意事项

- 不得使用放大镜 + 地球的“泛搜索”式构图（与 Google/Bing 混淆）。
- 图形以几何圆角与对称/准对称为主，避免复杂拟物与手绘笔触，保持“基础设施”的冷静与可靠感。
- 开源发布前请确认所有几何图形为原创（不套用商业图库模板），避免版权风险。
